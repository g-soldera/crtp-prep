# CRTP Prep

Estudo pessoal para a certificação Certified Red Team Professional (Altered Security).

## Estrutura

```
crtp-prep/
├── 00-fundamentos/        # AD basics, conceitos essenciais antes de atacar
├── 01-enum/               # Domain Enumeration
├── 02-local-privesc/      # Local Privilege Escalation
├── 03-lateral-movement/   # Movimentação lateral
├── 04-domain-privesc/     # Domain Privilege Escalation
├── 05-persistence/        # Domain Persistence & Dominance
├── 06-cross-trust/        # Cross Trust Attacks (child→parent, inter-forest, MSSQL)
├── 07-adcs/               # AD Certificate Services attacks
├── 08-bypass/             # MDE / MDI / AMSI / CLM bypass
├── lab/                   # Documentação do lab local (topologia, VMs, configs)
└── tools/                 # Notas sobre ferramentas (uso, flags, dicas)
```
